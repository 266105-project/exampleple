# FocusDo — 모던 심플 투두리스트 (To-Do List)

> 미려하고 직관적인 인터페이스로 오늘의 할 일을 빠르게 기록하고 관리하는 모던 웹 애플리케이션입니다.

![FocusDo Preview](https://raw.githubusercontent.com/266105-project/exampleple/main/preview.png)

## ✨ 주요 기능
- **할 일 등록 (Create):** `Enter` 키 또는 추가 버튼으로 신속하게 할 일 등록
- **목록 조회 및 진행률 (Read & Progress):** 실시간 완료율(%) 바와 남은 작업 통계 카드 제공
- **완료 토글 (Update):** 커스텀 체크박스 인터랙션 및 부드러운 취소선 애니메이션
- **항목 삭제 (Delete):** 항목 제거 시 페이드아웃 마이크로 애니메이션 지원
- **데이터 자동 저장 (Storage):** 브라우저 `localStorage`를 통해 새로고침 후에도 데이터 유지
- **상태별 필터:** 전체 / 진행 중 / 완료 탭을 통한 효율적인 목록 보기
- **키보드 단축키:** `/` 키 입력 시 바로 입력창으로 포커스 이동

## 🛠 기술 스택
- **HTML5:** 시맨틱 웹 표준 마크업, 접근성(ARIA) 준수
- **CSS3:** 바닐라 CSS, 글래스모피즘(Glassmorphism), 다크 테마 디자인 시스템
- **JavaScript (ES6+):** 바닐라 JS, 상태 관리 및 이벤트 위임, 로컬 스토리지 연동

## 🚀 실행 방법
별도의 빌드나 의존성 설치 없이 `index.html` 파일을 브라우저로 열면 즉시 실행됩니다.

```bash
# 로컬 개발 서버 실행 (선택 사항)
npx serve .
```
